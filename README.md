# Internship Projects

This repository contains six internship tasks focused on data analysis, machine learning, recommendations, interview generation, and support automation.

## Tasks

- **Task 1:** Internship prediction application
- **Task 2:** Sentiment analysis of company reviews
- **Task 3:** Personalized learning-path recommender
- **Task 4:** AI-assisted interview kit generator
- **Task 5:** Skill-gap analysis and course recommendations
- **Task 6:** Support ticket classification and FAQ assistance

Each task includes its own source code, data, documentation, and application files where applicable.
